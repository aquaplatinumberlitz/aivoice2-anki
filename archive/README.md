# Hồ sơ lịch sử — đọc sau tài liệu hiện hành

Cài phần mềm: [Quickstart A–Z](../docs/QUICKSTART_VI.md).
Sửa code hiện hành: [Development](../docs/DEVELOPMENT_VI.md).
Tìm tài liệu cũ: [Archive index](../docs/ARCHIVE_INDEX_VI.md).

Thư mục này trước đây tên developer-kit. Source addon và GUI helper đang
phát triển đã chuyển về ../src; chỉ giữ research source, probe, plan,
finding và evidence theo thời điểm ở đây. Backend WAV cũ chỉ còn trong
Git/tag v0.2.0, backend hiện hành ở repo aivoice2api.

Đường dẫn/lệnh trong hồ sơ có thể trỏ workspace đã xóa, prototype cũ hoặc
file ngoài gói. Không chạy probe lên app/prefix khách. Dùng checkout/tag
đúng mốc để tái hiện; ghi rõ binary hash và giới hạn quan sát của evidence.
