# Chỉ mục tài liệu Anki và bộ cài

**Lần đầu: [Quickstart A–Z](QUICKSTART_VI.md).** Một luồng duy nhất cho bộ cài
0.3.1/backend 0.1.0, Anki và vntext; đọc xong sẽ biết cách nghe câu mẫu ở cả hai app.

| Bạn là / việc cần làm | Thứ tự đọc |
|---|---|
| Người dùng cài lần đầu | [Quickstart](QUICKSTART_VI.md) → [môi trường](ENVIRONMENT_VI.md) nếu thiếu gói |
| Đã cài, học thẻ Anki | [Addon](ADDON_VI.md) |
| Thêm/gỡ giọng | [Quản lý giọng](VOICES_VI.md) |
| Đang gặp lỗi | [Hỗ trợ](SUPPORT_VI.md) |
| Dev mới tham gia | [Development](DEVELOPMENT_VI.md) → [kiến trúc](ARCHITECTURE_VI.md) → [đóng gói](INSTALLER_VI.md) |
| Tra finding/bằng chứng/plan trước đây | [Archive index](ARCHIVE_INDEX_VI.md) → file đúng mốc/binary |
| Được gửi link guide cũ | [AIVOICE2_CONNECT_VI](AIVOICE2_CONNECT_VI.md), trang chuyển hướng được giữ |

Source đang dùng ở `src/`; docs hiện hành ở đây. `archive/` là lịch sử,
không phải code mặc định của bộ cài. Tests installer ở `tests/`. Gói bàn
giao giữ Quickstart và ảnh minh họa để khách đọc được khi chưa đăng nhập GitHub.

Backend có tài liệu kỹ thuật riêng, không bắt buộc đọc để cài lần đầu:

[chẩn đoán/nâng cấp](https://github.com/aquaplatinumberlitz/aivoice2api/blob/main/docs/CONNECT_VI.md),
[API](https://github.com/aquaplatinumberlitz/aivoice2api/blob/main/docs/API_VI.md),
[build backend](https://github.com/aquaplatinumberlitz/aivoice2api/blob/main/docs/RELEASE_VI.md).
